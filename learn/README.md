# 雜誌英語闖關（本機版）

用雜誌單元做成的英語學習路徑：一課 3–5 分鐘，有單字卡、聽音辨字、配對、填空、排句子、跟讀口說（語音辨識）、文法練習、閱讀測驗、開口說自由回答，搭配 XP、連續學習天數、每日目標、錯題本與單字間隔複習。

全部是靜態網頁（HTML + JavaScript），不需要安裝任何東西，也不需要網路（語音辨識除外）。進度存在你電腦的瀏覽器裡。

## 怎麼開啟

**最簡單：** 直接雙擊 `index.html`，用 Chrome 或 Safari 開啟。

**要用麥克風跟讀時（建議）：**

- Mac：雙擊 `start-mac.command`（第一次若被擋，按右鍵 →「打開」）。它會在本機開一個小伺服器，並自動打開 `http://localhost:8765`。
- Windows：雙擊 `start-windows.bat`。

用 localhost 開啟時，瀏覽器只會問一次麥克風權限；直接開檔案時，有些瀏覽器會每次都問，或不允許使用麥克風。

| 功能 | 需要什麼 |
| --- | --- |
| 朗讀（單字、課文、例句） | 任何新版瀏覽器，離線可用（使用系統內建英文語音） |
| 語音辨識（跟讀評分、開口說） | Chrome 或 Safari，**需要網路**（瀏覽器會把聲音送到 Google／Apple 辨識） |
| 進度 | 存在這台電腦的這個瀏覽器；在「我的」頁可以匯出／匯入備份 |

### 讓朗讀聲音更自然

App 會自動挑電腦上最自然的英文聲音（在「我的 → 朗讀聲音」可以看到每個聲音的等級：自然 > 進階 > 良好 > 一般）。

1. **最推薦：用 Microsoft Edge 開啟。** Edge（Mac、Windows 都有）內建免費的 Natural 神經語音（Ava、Andrew、Emma…），最接近真人，需要連網。
2. **Mac 離線：** 系統設定 → 輔助使用 → 朗讀內容 → 系統聲音 → 管理聲音 → 英文（美國）→ 下載「Ava（進階）」或「Zoe（進階）」，重開瀏覽器後選它（Safari 最容易抓到）。
3. **真人錄音：** 單元檔可以接 MP3（例如雜誌附的官方音檔），有錄音的句子會優先播放錄音，見 `units/_template.js` 的 audio 說明。

## 每個單元會自動產生的關卡

1. **單字 1、2…**：每 4 個字一課（單字卡 → 選意思 → 配對 → 聽音辨字／選英文 → 例句填空 → 拼字 → 跟讀例句）
2. **補充單字**
3. **課文聽讀 上／下**：逐段朗讀（字會跟著亮起來）、點字聽發音、每段理解小題、聽句子排字卡
4. **文法**：每個 Language Notes 重點一課（說明卡＋選擇、填空、排句子）
5. **跟讀口說**：聽 → 說 → 顯示哪些字沒說清楚；短句加上聽寫
6. **閱讀測驗**：可隨時打開課文
7. **開口聊一聊**：What Do You Think? 用說的或打字回答，附自我檢核與參考回答
8. **單元挑戰**：綜合 15 題

答錯的題目會在同一課最後再出現一次，並收進「錯題本」；單字依答題結果安排複習日期（1、2、4、7、15、30 天）。

## 新增雜誌單元

1. 複製 `units/_template.js`，改名（例如 `units/u02-xxx.js`），照註解填入課文、單字、文法、題目。
2. 打開 `units/manifest.js`，把檔名加進清單。
3. 重新整理網頁。

只有 `id`、`title`、`article` 是必填，其他欄位有填才會產生對應的關卡。

## 關於雜誌內容與 GitHub

這個 repo 是公開的，所以雜誌原文**不會**上傳：`units/` 裡只有範本與範例會進 git，你自己的單元檔（例如 `u01-benjamin-button.js`）和 `manifest.js` 只留在你的電腦（見 `.gitignore`）。若 `manifest.js` 不存在，App 會改載入示範單元。
